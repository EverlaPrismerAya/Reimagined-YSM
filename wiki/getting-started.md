# 安装与开始使用

## 安装模组

本仓库面向 Minecraft 1.20.1，提供 Forge 和 Fabric 版本。模组需要与对应加载器的官方 YSM 2.6.x 一起安装。

1. 确认游戏使用的加载器，选择对应版本。
2. 将官方 YSM 和 Reimagined YSM 放入游戏实例的 `mods/` 文件夹。Forge 还需要 Architectury API 9.2 或更高版本。
3. 启动游戏，进入世界后打开 YSM 模型选择界面。

搭建 Reimagined YSM 服务器时，服务端同样需要官方 YSM 与对应依赖。只想自己看到模型时，服务器无需安装模组，参见下文纯客户端模式。

模型、缓存和配置继续使用 `config/yes_steve_model`，已有文件无需改名。模组界面维护简体中文和英语。

## 放入模型

以下路径均从游戏实例文件夹开始计算。服务器共享模型放在服务器的对应目录。

| 用途 | 目录 | 谁能看到 |
| --- | --- | --- |
| 单人模型、服务器共享模型 | `config/yes_steve_model/custom/` | 单人自己；联机时由服务器向玩家提供 |
| 个人模型 | `config/yes_steve_model/client/` | 只有自己 |

支持包含 `ysm.json` 的模型文件夹、`.zip` 和 `.ysm`。文件夹模型应保留完整内容，例如 `custom/my_model/ysm.json`，不要只复制 `models/main.json`。

带脚本的导出模型通常包含同名 `.ysm` 和 `.rysm`。请把两个文件一起放在同一目录；更新时也一起替换。

进入世界后，在模型选择界面选择模型。第一次加载可能需要等待，完成后可看到动态预览。可以先安装[库内示例模型](examples.md)确认操作。

## 纯客户端模式

个人模型仅在自己的游戏中显示。其他玩家不会因为你选择了个人模型而看到相同外观。

在配置中启用「强制纯客户端模式」后，本地模型都按个人使用方式运行。服务器未提供 YSM 支持时，也可使用纯客户端模式。在此模式下，其他玩家显示 Minecraft 皮肤。

连接官方 YSM 服务器时，关闭强制纯客户端模式后如需恢复服务器模型，请重新连接。

## 遇到问题

| 情况 | 先检查什么 |
| --- | --- |
| 模型没有出现在列表 | 目录是否属于当前游戏实例；文件夹内是否有 `ysm.json`；模型是否多套了一层目录 |
| 模型出现，但脚本效果缺失 | 同名 `.rysm` 是否一同安装；是否运行 Reimagined YSM；更新时是否替换了两个文件 |
| 其他玩家看不到模型 | 是否放在 `client/` 或启用了强制纯客户端模式；查看[联机说明](multiplayer.md) |
| 旧模型的物理或材质失效 | 按照[旧模型升级说明](compatibility.md#旧模型升级)生成新版副本 |
| Blockbench 中看不到摆动 | 编辑器提供静态辅助，动态效果需要进入游戏查看 |

不同模组与光影组合的效果可能不同。GPU 加速会根据环境自动选择是否使用，开启后不保证每个模型都更快。修改物理、材质或光影设置后，请以游戏中的表现为准。
