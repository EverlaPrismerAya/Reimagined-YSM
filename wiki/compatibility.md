# 兼容性与饰品联动

## 联机环境

| 环境 | 使用说明 |
| --- | --- |
| 客户端与服务端均安装 Reimagined YSM | 使用模型按需加载和支持同步的脚本功能；两端仍需安装官方 YSM |
| Reimagined YSM 客户端连接官方 YSM 服务端 | 提供官方 2.6.x 协议兼容；已针对 Forge 官方 2.6.5 适配，其他组合请分别确认 |
| 官方 YSM 客户端连接 Reimagined YSM 服务端 | 暂不支持 |
| 服务端未安装 YSM | 使用纯客户端模式，模型仅自己可见 |

连接官方服务器时，远程模型按官方方式加载，不提供本模组的按页或土豆远程下载。退出强制纯客户端模式后，如出现提示，请重新连接服务器。Fabric 联机组合需单独确认。

## 模型文件

兼容官方 YSM 2.6.x 模型格式。带脚本的导出模型由同名 `.ysm` 和 `.rysm` 组成，分享和安装时应一起提供。

官方 YSM 不加载 `.rysm` 脚本包。基础模型可以使用，但脚本控制的动画与新增效果可能缺失。请在准备分享的环境中检查实际效果。

## 旧模型升级

旧版 RYSM 用组名前缀设置效果。当前版本除官方 `ysmGlow` 外，不再使用这些前缀。旧披风、尾巴或星空等效果失效时，请先升级模型。

1. 备份模型，并准备包含 `ysm.json` 的单个模型文件夹。
2. 按照[旧模型升级工具说明](../.legacy-physic-upgrade-tool/README.md)启动工具。
3. 选择模型文件夹和新的输出位置，生成升级副本。
4. 将副本放入游戏，检查动画和效果。

工具只处理文件夹模型，不直接处理 `.zip`、`.ysm` 或 `.rysm`。

## 饰品联动

Forge 版可为以下饰品添加模型定位组。定位组的枢轴、旋转、缩放和父组变换决定饰品位置。

| 模组或饰品 | 定位组 |
| --- | --- |
| 诡厄巫法及启示录：不洁圣冠、破碎之环、晋升之环 | `HaloLocator` |
| 诡厄巫法：启示录，终末之环 | `OdamaneHaloLocator` |
| 诡厄巫法：星翼幻想，使徒光环、哈迪斯光环 | `FantasyHaloLocator` |
| 秘法法术：伊始之环 | `EsotericHaloLocator` |
| 梦幻终焉：泡影之领域 | `FantasyEndingHaloLocator` |
| 妖怪们的归家：头饰与发饰 | `YoukaiHeadLocator` |

终末之环、秘法法术和梦幻终焉饰品默认按身体定位，其余按头部定位。为定位组设置变换可调整饰品位置。

模型通过 `ysm.has_any_curios` 检测对应 Goety 饰品时，由模型显示该饰品。标签查询 `has_any_curios_with_all_tags` 和 `has_any_curios_with_any_tag` 同样适用。安装 showmeurhalo 时，这些饰品由本模组的饰品层显示。

星翼幻想光环按 Curios 栏位顺序选择一个。装备哈迪斯光环时优先显示哈迪斯光环。
