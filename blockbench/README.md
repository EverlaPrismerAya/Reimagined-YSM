# Reimagined YSM 分组编辑器 3.1.0

在 Blockbench 的插件界面选择「从文件加载插件」，加载 `reimagined_ysm_physics_groups.js`。已安装旧版时请重载插件或重启 Blockbench。

- **分组编辑**：选择可导出、未锁定的普通骨骼组，可创建普通物理组、尾骨组、身体碰撞组、星空着色器组、描边组，或启用单面厚度。创建会将当前组标记为目标类型。
- **编辑已有组**：选择尾骨可修改物理参数和类型；选择星空/描边组可修改参数、预览生成名称、即时修改或取消效果标记。操作支持撤销。
- **视口辅助**：集中放置骨链/碰撞体积显示及点击选择开关；开启碰撞块点选会自动打开碰撞体积显示。
- 页签、显示开关及浮窗状态保存在本机，不写入模型。

新版使用普通组名和 `Rysm.group` 脚本属性，支持同一组组合兼容效果。「编辑脚本组属性」可同时设置物理、面向镜头、发光、单面厚度、星空、描边和帧动画。星空颜色使用不带 `#` 的六位 RGB，混色为 0–100%；描边颜色支持六位 RGB 或 `auto`，宽度为 0–64 像素。

旧源码文件夹或 ZIP 放入运行目录 `config/yes_steve_model/rysm_upgrade/`，启动或重载时备份并升级，成功移入 `custom/`；冲突或失败保留原输入。普通模型加载不再触发旧组名迁移。迁移后，先执行「导入模型脚本属性」，再编辑。保存生成 `rysm/scripts/blockbench.js`，保留手写 JS 和尚未接管的迁移声明；修改迁移脚本和手写文件前保存备份。

「JavaScript 编辑与预览」提供独立手写脚本编辑、保存、运行与停止。通过模拟 JSON 输入实体/Molang 数据、按键和远端同步输出；骨骼姿态、面向镜头与星空在视口预览，物理仍只显示骨链和碰撞辅助。JS 在隔离 Worker 中执行，超时自动停止，停止后恢复视口。桌面版在模型目录读写文件，网页版下载脚本供手动加入清单。

完整接口、目录、多人同步和预览范围见 [RYSM JS 文档](../docs/rysmjs.md)。

尾骨默认参数与当前游戏源码一致：阻尼 10、重力阱 3、回弹 16、最大偏转角 50°、空气阻力 0.5。

验证：

```sh
node --check reimagined_ysm_physics_groups.js
node reimagined_ysm_physics_groups.test.cjs
node reimagined_ysm_physics_groups.test.cjs --browser
```

参数与组名称的有效输入立即生效，无需点击应用。无效或尚未输入完整的值不会覆盖上次有效值；每次有效更改可撤销。
