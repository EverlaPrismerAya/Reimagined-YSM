# Reimagined YSM 编辑器 4.0

在 Blockbench 中编辑新版 RYSM JS 组属性和手写脚本，并在**编辑模式**显示静态物理辅助。

## 安装与模型目录

在 Blockbench 插件界面选择「从文件加载插件」，加载 `reimagined_ysm_physics_groups.js`。它已内置离线编辑器和解析器，只需这一个文件，无需联网或复制 vendor 目录。更新后重载插件。

将项目保存到包含 `ysm.json` 的模型目录或其子目录：

```text
my_model/
├─ ysm.json
├─ models/main.bbmodel
└─ rysm/
   ├─ manifest.json
   └─ scripts/
      ├─ generated.blockbench.js
      └─ main.js
```

使用普通组名，例如 `cape`、`cape_end` 和 `body_collider`。插件直接读取 `.bbmodel` 中的 `rysm_properties`，不解析或生成旧组名前缀，也不修改 Blockbench 的组名清洗规则。旧组名前缀模型请先使用根目录 `.legacy-physic-upgrade-tool/upgrade.py` 图形工具升级（仅文件夹格式）。

## 编辑组属性

1. 选择未锁定、可导出的组，打开「Reimagined YSM → 编辑组属性」，或使用浮动检查器。
2. 设置物理、末端、碰撞体、发光、面向镜头、单面厚度、星空、描边或帧动画。同组可叠加兼容效果。
3. 使用数值框、角度滑块、重力模式、开关和选色器设置参数；物理类型可选择普通物理骨或尾骨。每种效果可选择未声明（继承）、启用或明确禁用。
4. 点击确认应用，可撤销和重做。保存项目、保存/导出模型 JSON 或执行「写入模型 rysm 文件夹」生成脚本。自动备份不会写入模型脚本。

检查器提供创建物理骨/尾骨及末端、延长骨链和取消物理化操作。末端使用普通名称，角色保存在属性中。创建身体碰撞组后，可以添加、点选无 UV 方块，再使用原生工具调整。物理骨、末端和碰撞体角色互斥。

选中骨链任意物理骨或末端，点击「编辑整条骨链」。窗口列出整条同类型骨链，每节可单独展开编辑所有物理参数；留空继承父骨或类型默认值。「统一设置整条链」仅将已填写字段批量应用到所有骨骼，其他效果不变，确认后以一次撤销记录保存。

浮动检查器主页提供「创建新脚本」和「脚本编辑器」。创建后直接打开离线 CodeMirror，提供组名/事件/效果补全、行诊断、参数说明及 RGB 色块选色。

### 子模型组名

脚本以模型文件名（去掉 `.json`）限定非主模型，例如 `models/arrow.json` 中的 `Bow` 写为 `arrow.Bow`，`models/arm.json` 中的 `LeftArm` 写为 `arm.LeftArm`。主模型仍使用裸组名；组本身无需重命名。插件按当前导出的模型路径生成和导入限定名，补全还包含 `ysm.json` 引用的其他模型。保存同一个生成文件时会保留其他模型的声明。

从 RYSM 模型包导入几何时，插件通过原生 codec 导入事件保留源文件中区分大小写的合法组名（例如 `bow` 与 `Bow`），避免原生唯一名处理将 `Bow` 改为 `Bow2` 后失去关联；不修改全局组名清洗规则。

`group_modifier` 和 `pose` 均支持限定名。游戏端在导出 `.rysm` 时附带 `rysm/model-scopes.json`，将文件名与二进制模型角色对应起来；更换文件路径后请重新导出附件，旧游戏 JAR 需要更新才支持该行为。

启用 Export Empty Groups，确保空末端组被导出。单面厚度和帧动画要求组内一个可导出方块及一个有效 UV 面。

生成内容使用新版事件 API：

```js
// Generated by Blockbench / 由 Blockbench 自动生成。
// This file is overwritten on save. Write advanced logic in a separate script.
// 此文件会在保存时自动生成并覆盖，请勿在此编写高级内容；请使用独立脚本文件。
Rysm.model('group_modifier', event => {
  event.modify('cape').physics({g:9.8, s:20, a:90, c:1});
  event.modify('cape_end').end(true);
  event.modify('body_collider').collider(true);
  event.modify('sky').cosmic({sc:'3388FF', sa:25}).outline({color:'auto', width:2});
});
```

## 生成文件与升级保护

`generated.blockbench.js` 由表单维护，脚本窗口中只读。新建手写脚本禁止使用 `generated.` 文件名前缀。高级逻辑请写入 `scripts/main.js` 等独立文件。

打开模型时，插件会从 `save_path` 或 `export_path` 向上查找 `ysm.json`，按 `rysm/manifest.json` 顺序读取可完整识别的生成声明（包括 `scripts/prefix-migrated.js`），按普通组名精确关联到 `rysm_properties`。找不到或存在重名的组会提示，不猜测名称。检查器显示配置来源；自动关联保留当前项目已有编辑，同一配置不会在撤销后重新应用。外部配置更新仅刷新尚未编辑的自动关联属性。

「导入生成脚本属性」只读取能够完整识别的插件/升级器生成声明，不执行文件，也不反向解析任意手写逻辑。导入与写入会合并重复声明的字段；项目已接管的组使用项目属性。迁移文件中未接管的声明保留。

旧 `scripts/blockbench.js` 只有完整识别后才会迁移为 `scripts/generated.blockbench.js`，在清单中保留原加载位置，并备份原文件。检测到手写逻辑、同时存在新旧生成文件或其他冲突时保留原件并报告，停止本次写入。修复前请将高级内容手动拆分到独立文件。写入失败会尝试恢复文件。

## 内置 JavaScript 编辑器

打开「Reimagined YSM → JavaScript 编辑器」：

- 菜单或编辑器工具栏的「注册星空效果」可填写效果名称和 PNG 相对路径（每行一个），生成独立的 `scripts/cosmic.js` 草稿（重名自动编号）。保存脚本后，在组属性的星空效果中填写相同名称。贴图需自行放入模型的 `rysm/cosmic/<效果名称>/` 目录，注册表单不复制图片。
- 代码和补全列表优先使用本机的 Cascadia Mono、Cascadia Code、Consolas、Lucida Console，中文回退到 Microsoft YaHei UI；无需安装或下载字体。行高为 1.55，关闭编程连字。

- 文件下拉框切换脚本，输入 `scripts/名称.js` 后点击「新建」。`*` 表示未保存草稿。
- 提供行号、当前行强调、语法高亮、括号匹配、缩进，以及 API、参数模板和当前模型组名补全。
- 输入两个字符自动补全，`Ctrl+Space` 主动补全；↑/↓ 选择，Enter/Tab 插入，Esc 关闭候选。Tab 缩进两个空格，Shift+Tab 取消缩进。`Ctrl+S` 保存。
- 参数提示显示在编辑器下方。补全按当前 RYSM 事件筛选，支持自定义回调参数名；不进行完整 JS 类型推导。
- 错误和可静态确认的问题显示在对应行及诊断列表，点击定位。分析不执行脚本，也不能完全复现 Rhino 运行时检查。
- `sc`、`ac`、`color` 的六位 RGB 字面量显示色块；点击选色，写回不带 `#` 的 RGB。描边颜色也可使用 `auto`。
- 中文输入组合期间暂停补全。切换文件会询问保存或保留窗口内草稿；关闭时提供返回编辑、保存或丢弃选项。

桌面版保存到模型的 `rysm/` 并将新文件加入清单；已有文件修改前备份，检测到外部修改时停止覆盖。网页版或项目未处于模型目录时下载 JS 文件，需要自行加入清单。

切换项目后，旧窗口保留草稿并停止写入，可导出草稿。插件重载时将未保存草稿保存在原项目属性中。手写脚本与属性表单独立，不在 Blockbench 内运行。

完整 API 与示例见 [Wiki 脚本说明](../wiki/scripting.md) 和 [中文注释示例](../examples/rysmjs/README.md)。

## 编辑模式静态辅助

浮动检查器的「视口辅助」提供两个独立开关：

- **显示物理骨链**：骨链、末端方向与选中骨骼的角度范围。
- **显示碰撞体积**：骨骼碰撞半径与身体碰撞方块，包括无 UV 方块。

另可开启碰撞块或物理组点选。隐藏碰撞体积时暂停碰撞块点选。退出编辑模式、切换项目及卸载插件时清理辅助对象。

仅显示项目中的声明式属性，不模拟物理运动，不提供脚本运行、姿态、按键或星空高级预览。实际动态效果在 Minecraft 中验证。

## 开发检查

编辑 `src/plugin.js` 后重新生成单文件插件：

```powershell
node blockbench/build.cjs
node blockbench/build.cjs --check
node --check blockbench/reimagined_ysm_physics_groups.js
node blockbench/reimagined_ysm_physics_groups.test.cjs
node blockbench/reimagined_ysm_physics_groups.test.cjs --browser
./gradlew.bat :common:scriptChecks --offline
```

`--browser` 使用临时 Chromium 配置检查实际 CodeMirror、补全、诊断、颜色编辑、中文组合期间补全抑制、只读文件、草稿保护和清理。默认使用 Windows Chrome，可设置 `RYSM_CHROME` 指定路径。此检查不等于真实输入法或 Blockbench 实机验收。

离线依赖与许可见 [vendor/README.md](vendor/README.md)。
